
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：项目名 / 产品名 / 公司名 / 政策名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是型号 / 代号 / 没信息量的 teaser（如 "PowerTitan 3.0"、"Day 1"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "PowerTitan 3.0" + 来源 "阳光电源：新闻" → "阳光电源 PowerTitan 3.0 完成极限燃烧测试"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体型号时，用上位词（如"工商业储能系统"）兜底，绝不凭"行业常识"编一个具体型号 / 版本 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的项目、产品或新数据，就改写成“发布 / 推出 / 上线 / 并网 / 投运”。只有原标题明确宣布了发布、推出、上线、并网或投运，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、产品、项目名。
   例：原标题 "How virtual power plants earn revenue in spot markets" → "虚拟电厂如何从现货市场获得收益"，不能写成 "某公司发布虚拟电厂平台"。
   例：原标题 "How to size a C&I storage system" + 来源和正文明确是固德威 → "固德威如何为工商业储能系统选型"，不能只写成缺主体的 "如何为工商业储能系统选型"。
6. 本条的动作和背景里的旧发布要分清：原文把发布写成过去的事（“Last month we connected …”“上周我们并网了…”），本条是在讲用法、做演示或再次推广时，标题写介绍、演示或讲解，把发布交代成此前的事；不能写成“推出 / 发布 / 并网 / 投运”，否则读者会当成今天的新闻。只有原文明确某个项目或能力是现在才并网、投运或开放，才对那一项用对应动作。
   例：正文 "Last month we connected the project … Here is how the O&M works" → "天合富家介绍某项目并网后的运维做法"，不能写成 "天合富家投运某项目"。
